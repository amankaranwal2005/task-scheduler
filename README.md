# 📅 Task Scheduler in C

## 📌 About the Project
Task Scheduler is a console-based application developed using C programming to help users manage their daily tasks efficiently. It allows users to add, view, edit, and delete tasks with details such as task name, description, date, and time.

## ✨ Features
- Add new tasks with complete details.
- View all scheduled tasks.
- Edit existing task information.
- Delete tasks by task number.
- Manage up to 100 tasks per execution.
- Simple, interactive, menu-driven interface.

## 🛠️ Technologies Used
- **Language:** C
- **Libraries:** `stdio.h`, `stdlib.h`, `string.h`
- **Concepts:** Structures, arrays, functions, pointers, loops, and string handling.

## ⚙️ How to Run

Compile the program using GCC:

```bash
gcc task_scheduler.c -o task_scheduler
```

Run the application:

```bash
./task_scheduler
```

On Windows, run `task_scheduler.exe`.
